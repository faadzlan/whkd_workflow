#+title: LOAD-WORKFLOWPROFILE(1)
#+subtitle: Load the everyday workflow shortcuts into the current session

* NAME

Load-WorkflowProfile.ps1 - define the four everyday shortcuts (=bt=, =exp=, =mem=, =bye=) and the =wf= help command in the current PowerShell session

* SYNOPSIS

#+begin_src powershell
. C:\Users\faadz\Projects\whkd_workflow\tools\workflows\Load-WorkflowProfile.ps1
#+end_src

Must be *dot-sourced* (leading =. =). It is dot-sourced from the PowerShell 7 =$PROFILE= (=C:\Users\faadz\OneDrive\Documents\PowerShell\Microsoft.PowerShell_profile.ps1=), so it runs in every new Windows Terminal tab and prints one line: =bt, exp, mem, bye  (wf for more)=.

* COMMANDS

- =bt= :: Open the Bluetooth Settings page (via [[file:open-quick-settings.org][Open-QuickSettings.ps1]]). Win+A only has the toggle; this opens the full page for pairing.
- =exp [path]= :: Open File Explorer at the current directory or =path=. Equivalent to the built-in =ii .= / =explorer .=; kept because it is muscle memory.
- =mem= :: Top 10 processes by working set, in MB.
- =bye= :: Close all windows (via [[file:close-all-windows.org][Close-AllWindows.ps1]]).
- =wf= :: Print the shortcuts above, the scripts that are no longer loaded into every shell, and the whkd hotkeys.

* HISTORY: THE 2026-10-31 USAGE AUDIT

Until 2026-10-31 this file defined 27 commands (navigation, six Settings openers, system health, =work=/=clean-dl=, a five-command WSL bridge, =touch=/=which=/=findf=) and printed a ~30-line banner in every tab, costing ~0.2-0.25 s per tab.

An audit of PSReadLine history (=ConsoleHost_history.txt=, 1,304 lines; this toolset's commands first appear at line 809, matching the 2026-03-14 initial commit) found:

| Command | Trial burst (lines 809-1002) | Last ~300 lines |
|---------+------------------------------+-----------------|
| =bt= | 2 | 5 |
| =bye= | 0 | 6 |
| =mem= | 5 | 5 |
| =exp= | 7 | 5 |
| =proj= | 12 | 0 (replaced by zoxide =z=) |
| =work= | 9 | 0 |
| =syshealth=, =cpu=, =startup-apps=, =clean-dl=, =docs=, =dl= | 1-3 each | 0-2 |
| 14 others (=vol=, =wifi=, =disp=, =power=, =home=, =doctor=, all WSL helpers, =which=, =findf=, =touch=) | 0 | 0 |

Only the four still in steady use were kept. The underlying scripts (=Show-SystemHealth.ps1=, =Start-WorkEnvironment.ps1=, =Clear-Downloads.ps1=, =Go-ToProject.ps1=, =Open-QuickSettings.ps1=, =Test-WorkflowSetup.ps1=) are unchanged and still run by path and from the whkd hotkeys; the WSL bridge and =touch=/=which=/=findf= were deleted outright. History has no timestamps and does not capture whkd hotkey presses, so hotkey use was not measured.
