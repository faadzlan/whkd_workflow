#+title: LOAD-WORKFLOWPROFILE(1)
#+subtitle: Load all workflow shortcut functions into the current session

* NAME

Load-WorkflowProfile.ps1 - source all whkd_workflow shortcut functions
into the current PowerShell session

* SYNOPSIS

#+begin_src powershell
. .\tools\workflows\Load-WorkflowProfile.ps1
#+end_src

Must be *dot-sourced* (leading =. = before the path). Running it without
the dot executes it in a child scope and none of the functions persist.

* DESCRIPTION

Load-WorkflowProfile defines every shortcut function in this toolset
directly in the calling session - navigation, Settings shortcuts, system
health, the =work=/=bye=/=clean-dl= workflow wrappers, the WSL bridge,
and small file utilities. It is the =~/.bashrc= of this project: add one
line to =$PROFILE= and every shortcut below is available in every new
PowerShell session.

Unlike [[file:go-to-project.org][Go-ToProject.ps1]], which can also be run standalone, this file's
functions are only meant to be *sourced*, not executed directly - =proj=,
=bt=, =work=, etc. are defined as functions in the caller's scope, not
run once and exited. It dot-sources =Common.ps1= for the path/WSL
helpers shared with [[file:go-to-project.org][Go-ToProject.ps1]] and
[[file:start-work-environment.org][Start-WorkEnvironment.ps1]] (FINDING 8 of the 2026-07 workflow audit).

* PARAMETERS

None. All behavior comes from dot-sourcing; there is nothing to pass on
the command line.

* FUNCTIONS DEFINED

Navigation & Projects ::
- =proj <name> [-e|-t|-w|-m]= - one-line wrapper that forwards all
  arguments to [[file:go-to-project.org][Go-ToProject.ps1]], the single =proj= implementation
  (FINDING 7). Jump to a project from =projects.json= (Explorer /
  Terminal / WSL / Emacs); bare call changes directory. =proj list=
  shows all configured projects.
- =home=, =docs=, =dl= - =Set-Location= to =%USERPROFILE%=,
  =%USERPROFILE%\Projects=, =%USERPROFILE%\Downloads=.
- =exp [path]= - open File Explorer at the current or given path.

Settings Shortcuts ::
- =bt=, =vol=, =wifi=, =disp=, =startup-apps=, =power= - one-line
  wrappers around [[file:open-quick-settings.org][Open-QuickSettings.ps1]], which owns the =ms-settings:=
  URI table (single source of truth, FINDING 8).

System Health ::
- =syshealth= - runs [[file:show-system-health.org][Show-SystemHealth.ps1]].
- =mem=, =cpu= - top 10 processes by working set / CPU time.
- =doctor= - runs Test-WorkflowSetup.ps1 ("workflow-doctor"): checks for
  duplicate whkd processes, live-vs-repo whkdrc drift, and missing
  PowerShell modules.

Workflow Commands ::
- =work [path]= - runs [[file:start-work-environment.org][Start-WorkEnvironment.ps1]], forwarding =path= as
  =-ProjectPath= if given.
- =bye= - runs [[file:close-all-windows.org][Close-AllWindows.ps1]].
- =clean-dl [args]= - runs [[file:clear-downloads.org][Clear-Downloads.ps1]], forwarding all arguments.

WSL Bridge (absorbed the retired =wsl-bridge.ps1= - see [[file:wsl-bridge.org][wsl-bridge.org]]) ::
- =wsl-path [path]= - convert a Windows path to =/mnt/<drive>/...= form
  (current directory if omitted).
- =win-path <wslPath>= - convert =/mnt/<drive>/...= back to =<Drive>:\...=.
- =cp-wsl [path]=, =cp-win [path]= - copy the WSL- or Windows-format path
  to the clipboard.
- =wsl-here [cmd]= - run =cmd= (default =bash=) inside WSL at the
  Windows-current-directory's WSL equivalent.
- =wsl-status= - show =wsl -l -v= output and =.wslconfig= contents.
- =wsl-explorer= - open the current directory in File Explorer.

File Utilities ::
- =touch <path>= - create the file, or bump its =LastWriteTime= if it
  already exists.
- =which <name>= - print the resolved path of a command.
- =findf <name> [path]= - recursive =*name*= filename search under
  =path= (default =.=).

* FILES

- =Common.ps1= (same directory) :: dot-sourced for =Resolve-ProjectPath=,
  =Test-IsWSLPath=, =ConvertTo-WSLPath=, =ConvertTo-WindowsPath=,
  =Convert-WSLPathToUNC=, =Get-WSLHomeDir=.
- =projects.json= (same directory as [[file:go-to-project.org][Go-ToProject.ps1]]) :: shared project
  alias config; read by =Go-ToProject.ps1= on every =proj= call, since
  this file's =proj= is only a forwarding wrapper.

* EXIT STATUS

Always exits normally after printing the loaded-shortcuts summary;
there is no failure mode beyond individual functions failing when later
invoked.

* EXAMPLES

Load once in an interactive session:
#+begin_src powershell
. .\tools\workflows\Load-WorkflowProfile.ps1
#+end_src

Auto-load on every new PowerShell session, added to =$PROFILE=:
#+begin_src powershell
notepad $PROFILE
# add this line at the end:
. C:\Users\faadz\Projects\whkd_workflow\tools\workflows\Load-WorkflowProfile.ps1
#+end_src

* NOTES

- =proj= no longer has its own implementation here - see FINDING 7 of
  [[file:workflow-audit-2026-07.org][the 2026-07 workflow audit]] for why two divergent copies used to exist
  and how that was a real (if currently invisible) bug: whichever script
  ran last silently won for the rest of the session.
  [[file:go-to-project.org][Go-ToProject.ps1]] is now the only place project/WSL path logic lives.
- =mem=/=cpu= are quick one-liners; for the fuller dashboard (disk,
  network, startup impact) use =syshealth=.
